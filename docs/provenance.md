# Example content, privacy and provenance


`YourAgency` and the `*.example.com` destinations are placeholders. The prompt's catalog, prices, schedules, delivery periods and financing terms are **illustrative configuration**, not a current commercial offer. Published customer success stories and third-party comparisons have been removed from the current export; do not invent testimonials or project impact.

Credentials and deployment identifiers in these exports are placeholders; `pinData` is empty. This does **not** make the workflow safe to expose publicly as an unauthenticated service. Public GitHub ownership and authorship remain visible. A local-machine author address exists in the initial commit; it is not a credential, and this update does not erase Git history. Earlier revisions also retain the previous prompt content. See [publication and history notes](security.md).
